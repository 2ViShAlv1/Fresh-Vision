# Practice School-II presentation

| File | What it is |
| --- | --- |
| `Fresh_Vision_PSII_Presentation.pptx` | The deck, 14 slides, A4 landscape — follows the PS-II template order and its blue/white styling |
| `Fresh_Vision_PSII_Presentation.pdf` | Same deck exported to PDF for quick viewing |
| `build_deck.js` | pptxgenjs generator that produces the .pptx — edit and re-run to regenerate |
| `assets/` | Application screenshots used on the results slide |

Regenerate the deck with:

```bash
npm install pptxgenjs
node presentation/build_deck.js
```
